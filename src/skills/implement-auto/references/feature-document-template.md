## Section Ownership

| Section | Filled by | Tool | When |
|---------|-----------|------|------|
| §0 Metadata | step-00-init-auto | Write | At creation |
| §1 Contexte | step-00-init-auto | Write | At creation (from spec) |
| §2 Plan | step-02-plan-auto | Edit | After plan validation |
| §3 Implementation | step-03-code-auto | Edit | After each component (incremental) |
| §4 Revue | step-04-review-auto | Edit | After all reviews |
| §5 Finalisation | step-05-document-auto | Edit | At documentation phase |

## Rules

- Created by step-00-init-auto using Write tool
- Updated by each step using Edit tool (never overwrite entire doc)
- Path stored in JSON output `feature_doc` field
- Status updated to COMPLETED/PARTIAL/FAILED by step-06-finish-auto
- §0-§5 section structure aligned with implement's Feature Document for consistency
