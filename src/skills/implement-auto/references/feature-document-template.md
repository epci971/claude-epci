# Feature Document Template (Auto)

> Template for the Feature Document generated by implement-auto.
> Location: `docs/features/{feature-slug}-{timestamp}.md` in the target project.

## Template

```markdown
# Feature: {feature-slug}

## Metadata

| Champ | Valeur |
|-------|--------|
| Slug | {feature-slug} |
| Date | {YYYY-MM-DD HH:mm} |
| Branche | feature/{feature-slug} |
| Spec source | {spec-path} |
| Status | IN_PROGRESS |
| Mode | implement-auto (headless) |

## Objectif

{extracted from spec: objective/description}

## Criteres d'acceptation

{extracted from spec: acceptance criteria as checklist}

## Plan d'implementation

> Auto-generated from step-02-plan-auto

| # | Composant | Fichier | Status |
|---|-----------|---------|--------|
{plan components table}

## Implementation Log

> Updated incrementally by step-03-code-auto

{per-component TDD results}

## Review

> Auto-generated from step-04-review-auto

### Self-Review Results
{self-review checklist results}

## Resume Executif

> Generated by step-05-document-auto

{2-3 paragraph summary of what was implemented}
```

## Section Ownership

| Section | Filled by | When |
|---------|-----------|------|
| Metadata | step-00-init-auto | At creation |
| Objectif | step-00-init-auto | At creation (from spec) |
| Criteres | step-00-init-auto | At creation (from spec) |
| Plan | step-02-plan-auto | After planning |
| Implementation Log | step-03-code-auto | After each component |
| Review | step-04-review-auto | After self-review |
| Resume Executif | step-05-document-auto | At documentation phase |

## Rules

- Created by step-00-init-auto using Write tool
- Updated by each step using Edit tool (never overwrite)
- Path stored in JSON output `feature_doc` field
- Status updated to COMPLETED by step-06-finish-auto
