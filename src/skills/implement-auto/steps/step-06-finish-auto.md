# Step 06: Finish (Auto)

## MANDATORY EXECUTION RULES:

- NEVER call AskUserQuestion
- ALWAYS run final test suite
- ALWAYS commit changes (if any)
- ALWAYS determine final status accurately

## EXECUTION PROTOCOLS:

### 1. Run Final Test Suite

Execute the full test suite one last time:

```bash
{test_command_full_suite}
```

Record final results:
- `checks.tests.status` = "pass" or "fail"
- `checks.tests.count` = total tests
- `checks.tests.failures` = failing tests

### 2. Determine Final Status

Apply status decision logic:

```
IF all components SUCCESS AND all tests pass:
  status = "SUCCESS"
  exit_reason = null

ELIF some components FAILED but others SUCCESS:
  status = "PARTIAL"
  exit_reason = "partial_implementation"

ELIF circuit_breaker_triggered:
  status = "FAILED"
  exit_reason = {circuit_breaker_reason}

ELIF all components FAILED:
  status = "FAILED"
  exit_reason = "all_components_failed"
```

### 3. Stage and Commit Changes

IF there are changes to commit:

```bash
git add -A
git commit -m "{commit_message}"
```

Commit message format:
```
feat({scope}): {feature-slug} - implement-auto

{brief description of what was implemented}

Components: {success}/{total} successful
Tests: {tests_passing} passing, {tests_failing} failing
Status: {status}

Generated by implement-auto (headless EPCI)
```

If commit fails (pre-commit hook):
- Add warning to JSON
- Do not retry (headless mode)
- Status remains as determined

### 4. Update Feature Document Status

Use Edit tool to update metadata status:

```
old: "| Status | IN_PROGRESS |"
new: "| Status | {COMPLETED or PARTIAL or FAILED} |"
```

### 5. Update JSON Output

Update `.implement-auto-output.json`:
- `phases.completed` += "finish"
- `phases.current` = "output"
- `status` = final status
- `exit_reason` = final exit reason
- Finalize all metrics

## CONTEXT BOUNDARIES:

- This step expects: All implementation results, review findings
- This step produces: Final status, committed changes, updated JSON

## NEXT STEP TRIGGER:

Always proceed to step-07-output-auto.md for final JSON write.
