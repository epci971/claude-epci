## Resume Executif

Implemented the task selection algorithm for the OpenClaw Notion Task Runner. The module (`task_selector.py`) provides the core intelligence for determining which task to execute next from a Notion database. It parses raw Notion API page objects into flat task dicts, filters eligible tasks by status, sorts by priority with Story ID tiebreaker, resolves dependency chains via "Bloque par" relations, and detects circular dependencies using DFS-based cycle detection.

The implementation follows the existing codebase conventions: Python stdlib only, Google-style docstrings, full type hints (Python 3.9+). The main entry point `select_next_task()` orchestrates the full pipeline: parse, filter, detect cycles, resolve deps, sort, and return the highest-priority unblocked task.
